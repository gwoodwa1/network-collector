# Examples

- [`modular/`](modular/) demonstrates recursive role imports, labelled inventory, groups, parser modules, concurrent device execution, lifecycle events, and bounded monitoring.
- [`workflow-operations/`](workflow-operations/) contains complete playbooks for conditions, loops, parameterized workflows, recovery and rollback, approval gates, parallel branches, recurring schedules, OpenConfig facts, label selectors, canary rollout, failed-device replay, and reload/reconnect handling.

Examples use documentation-only addresses from `192.0.2.0/24`. Update inventory and credentials for your lab before execution.

The workflow cookbook collectively covers inventory labels and selectors, groups, parser modules, typed validation, variables, conditions, loops, reusable workflows, retries, recovery, rollback, approvals, concurrent branches, canary rollout, failure thresholds, recurring schedules, lifecycle events, failed-device replay, OpenConfig facts, SSH security migration, and reload/reconnect handling. Start with the table in [`workflow-operations/README.md`](workflow-operations/README.md) and copy only the controls appropriate for your platform.
