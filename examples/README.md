# Examples

- [`modular/`](modular/) demonstrates recursive role imports, inventory groups, parser modules, concurrent device execution, and bounded monitoring.
- [`workflow-operations/`](workflow-operations/) contains complete playbooks for conditions, loops, parameterized workflows, recovery and rollback, approval gates, parallel branches, and recurring schedules.

Examples use documentation-only addresses from `192.0.2.0/24`. Update inventory and credentials for your lab before execution.
